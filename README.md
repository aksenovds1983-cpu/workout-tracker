# Трекер тренировок
Приложение для записи и отслеживания тренировок. Пользователь добавляет записи о выполненных упражнениях, указывая тип тренировки, длительность и дату. Все данные сохраняются в браузере и не пропадают при перезагрузке страницы.

Приложение показывает список тренировок, позволяет удалять записи, считает сожжённые калории и выводит общую статистику.
