# 🏋️ Workout Tracker (Трекер тренировок)

**Workout Tracker** — это веб-приложение для удобной записи и отслеживания тренировок. Пользователь может добавлять записи о выполненных упражнениях (указывая тип, длительность и дату), удалять их, а также просматривать общую статистику по сожжённым калориям и проведённому времени.

Проект написан на «чистом» JavaScript (Vanilla JS) без использования сторонних библиотек и фреймворков. Основная задача — продемонстрировать навыки работы с нативным DOM API, модульным подходом и локальным хранилищем.

## 🛠 Технологический стек

- **HTML5** — семантическая разметка страницы.
- **CSS3** — адаптивная вёрстка, Flexbox, тёмная и светлая темы, CSS-переменные, плавные переходы (transitions).
- **JavaScript (ES6+)** — современный синтаксис, нативные методы DOM, работа с массивами и объектами.
- **ES-модули** — код разделён на независимые модули (`import`/`export`).
- **LocalStorage API** — данные сохраняются локально в браузере пользователя и не пропадают при перезагрузке страницы.

## 📄 Структура сайта

Сайт состоит из трёх страниц:
1. **Главная (`index.html`)** — приветственная страница.
2. **Трекер (`app.html`)** — основное приложение с формой и списком тренировок.
3. **О проекте (`about.html`)** — информация о приложении и технологиях.

## ⚙️ Функциональность

- **Добавление тренировки.** Пользователь выбирает тип (кардио или силовая), длительность в минутах и дату. После нажатия кнопки «Добавить» запись сохраняется и появляется в списке.
- **Подсчёт калорий.** Автоматический расчёт сожжённых калорий на основе типа тренировки и её длительности.
- **Удаление записей.** Любую тренировку можно удалить из списка нажатием на соответствующую кнопку.
- **Блок статистики.** Динамический подсчёт общего количества тренировок, суммарного времени (в минутах) и общего количества сожжённых калорий.
- **Смена темы.** Переключение между тёмной и светлой темой на всех страницах с сохранением выбора в браузере.
- **Сохранение состояния.** При перезагрузке страницы или закрытии браузера все данные остаются на месте благодаря `localStorage`.
