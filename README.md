# -
Заметки — это простое веб-приложение для создания и хранения заметок.

Пользователь вводит текст в поле ввода и нажимает кнопку «Добавить». На странице появляется карточка с заметкой. Каждую заметку можно удалить, нажав на кнопку рядом с ней. Если заметок нет, приложение показывает подсказку: «У вас пока нет заметок. Добавьте первую!».

Все заметки автоматически сохраняются в браузере, поэтому при перезагрузке страницы они не пропадают.
